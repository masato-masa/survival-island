# むじんとうスローライフ — M1 設計

元の仕様書（ドラフト v0.2）を Web で試作する。M1 は「核のループ」:
歩く → 伐採・採掘 → 経験値 → スキル → 境界を壊して次のエリア → クラフト →
模様替えで配置 → 島ポイント → 島レベル → スキル上限・レシピ・種が増える。畑も入る。

**M1 に入れないもの:** 料理・釣り・交易・ダンジョン・課金・広告。

数値はすべて `src/game/data.ts`、型は `src/game/types.ts`。この文書は仕組みを書く。

## 構成

```
src/game/    純粋な TS。React・DOM・Canvas に依存しない。vitest で全部テストする
  types.ts   型（契約）          data.ts  数値・定義・マップ
  world.ts   MAP → World（エリア判定・畑の区画・配置スペース）
  time.ts    スタミナの現在値、作物の成長、資源の復活
  rules.ts   スキル段階の上限、ダメージ、クールダウン、覚えているレシピ・種
  actions.ts 叩く・植える・収穫・看板・宝箱・スキル獲得・クラフト・配置
  score.ts   島ポイント（得点＋統一ボーナス）と島レベル
  target.ts  プレイヤー位置からアクション対象を選ぶ、当たり判定（歩けるか）
  save.ts    新規セーブ、localStorage 読み書き、形式の補正
  store.ts   実行時の状態（セーブ＋時計）。React と Canvas の両方が購読する
src/render/  Canvas 描画。sprites.ts（ドット絵の定義）、renderer.ts、camera.ts
src/input/   ポインタ入力（ドラッグ＝移動、タップ＝アクション、ピンチ＝ズーム）
src/ui/      React の画面。shared/ は shared-ui からの生成物（直接編集しない）
```

## 時間

- **時計は `store.now()`**＝`Date.now() + devOffset`。開発者メニューの「1 時間進める」は devOffset を増やす。ゲームロジックは必ず `now` を引数で受け取り、`Date.now()` を直接呼ばない。
- **スタミナ:** 保存するのは `{value, updatedAt}`。現在値は
  `min(max, value + floor((now - updatedAt) / 3分))`。消費するときはまず現在値に正規化し
  （updatedAt は回復に使った分だけ進める。上限に達していたら now にする）、それから引く。
  アプリを閉じていても回復する。
- **作物:** `plantedAt + growMs <= now` で収穫可。成長段階は 0〜1 の割合で描画側が 3 段に分ける。
- **資源の復活:** 壊れた木・岩は `destroyedAt + respawnMs` を過ぎたら元に戻る（`nodes` から消す）。
  プレイヤーがそのマスに立っているときは戻さない。境界は戻らない。

## 行動

| 行動 | スタミナ | 経験値 | 条件 |
|---|---|---|---|
| 叩く（木・岩・境界） | 1 | 1 | 太い木 axePower≥1、硬い岩 pickHard≥1、境界は AREAS の条件 |
| 植える | マスごとに 1 | 同 | 看板で作物を選んでいる、マスが空 |
| 収穫 | マスごとに 1 | 同 | 成長済み |
| クラフト | 家具ごと | 同 | 覚えている、素材がある |
| 宝箱を開ける | 0 | 0 | 一度だけ。レシピを覚える |

- ダメージは `damageForLevel(パワー系の段階)`（木＝axePower、岩＝pickHard）。
- クールダウンは `ACTION_COOLDOWN_MS × (1 − 0.1 × 速度スキル)`。畑は速度スキル 0 扱い。
- スタミナが足りないときは何もしない（`noStamina`）。範囲の種まきで足りないときは、足りる分だけ行う。
- 範囲（farmRange）は `FARM_RANGE` の相対位置のうち、同じ区画のマスで条件を満たすものだけ。
- 収穫量は `harvestAmount(farmYield)` をマスごとに。
- **境界:** 境界マス（1 エリアに 2 マス）をすべて壊すとエリアが開く（`areaOpened`）。開いたかどうかは「そのエリアの境界ノードがすべて壊れている」で判定し、別に保存しない。

## スキル

- 経験値は共通。どのスキルにも使える。`SKILL_COST[次の段階 - 1]` を消費。
- 段階の上限は `min(skill.maxLevel, 島レベル)`。振り直しなし。
- スタミナ上限 = `STAMINA_BASE + 5 × staminaMax`。

## 島ポイントと島レベル

- 島ポイント = 配置した家具の得点合計 + エリアごとの統一ボーナス。
- 統一ボーナス: エリア内の同じシリーズの家具数で `SERIES_BONUS` の最も上の段を 1 つ採る（シリーズごと・エリアごとに加算）。
- 配置・取り外しのたびに `maxPoints = max(maxPoints, 現在)`。島レベルは maxPoints で決まる（下がらない）。
- 島レベルで増えるもの: スキル上限、レシピ（`learn.level`）、種（`CROPS.unlockLevel`）。

## 配置（模様替えモード）

- スペースの属性と家具の属性が一致しないと置けない。1 スペースに 1 つ。
- 置く: 持ち物の家具を 1 減らしてスペースへ。既に置いてあれば入れ替え（元の家具は持ち物に戻る）。
- しまう: 持ち物に戻す。
- 置いた家具は当たり判定を持つ（**道だけは上を歩ける**）。空きスペースは歩ける。

## 操作

- **ドラッグ＝移動。** 指を置いた点を中心にした見えないスティック。7px 動いたらドラッグ扱い。
  方向はベクトルそのまま（8 方向に丸めない）、速さは 40px で最大（`WALK_SPEED`）。
  指が中心から 70px 以上離れたら中心を指の方へ引きずる（ツルハシ王式の浮くスティック）。
  スティックの位置を薄い円で描く。
- **タップ＝アクション。** 7px 未満の移動で離したらタップ。通常モードでは「今ハイライトされている対象」を実行（押した位置は関係ない）。模様替えモードでは押した位置の配置スペースを選ぶ。
- **ピンチ＝ズーム。** 2 本指で拡大縮小。0.6〜2.0 倍（既定の見え方に対する倍率）。
- **PC 用:** 矢印キー / WASD で移動、スペース / Enter でアクション、ホイールでズーム。
- **対象の選び方:** 足元の中心から `TARGET_RADIUS` 以内のマス中心のうち最も近いもの。同じ距離なら向いている方。
  候補: 立っている資源、看板、宝箱（未開封）、畑のマス（植えられる or 収穫できる）。成長中のマスは候補にしない。
  条件を満たさない資源（スキル不足）も候補にするが、赤いハイライトにして、タップすると理由を出す。
- **当たり判定:** 足元の箱（幅 0.6 × 高さ 0.35 マス）。水・立っている資源・看板・宝箱・置いた家具（道以外）は通れない。x と y を別々に動かして壁に沿って滑る。

## 画面

共通 UI（`shared-ui/`）の構造に従う。

```
行1  [戻る]         エリア名          [?] [設定]
行2  スタミナ 24/30（ゲージ）  島Lv 2  経験値 12
     マップ（Canvas、残りの高さすべて）
ツール行  もちもの  スキル  クラフト  もくひょう  模様替え
```

- **行 2 はスタミナゲージ・島レベル・経験値。** 次の回復までの残り秒も小さく出す。
- シート: もちもの（素材・作物・家具の数）、スキル（系統ごと、段階の丸、必要経験値、獲得ボタン、上限による鍵）、
  クラフト（家具の一覧、属性・シリーズ・得点・素材、作るボタン）、もくひょう（島ポイント・次のレベルまで・
  次で増えるもの・エリアの開放状況と必要スキル）、看板（作物を選ぶ）、配置（そのスペースに置ける家具・しまう）。
- 模様替えモード: ツール行の模様替えボタンが押された状態になる。マップ上の配置スペースを属性の色の枠と記号で表示。アクションのハイライトは出さない。
- ホーム: タイトル・「はじめる／つづきから」・進み具合（島レベル・開いたエリア数）。右下に「テスト用」。
- 開発者メニュー: スタミナ全快、経験値 +50、素材 +20（木材・石・銅・作物）、時計を 1 時間進める、島ポイント上限を次のレベルへ、記録を消す。
- はじめて遊ぶとき: 神のお告げ（数行）→ 万能工具を授かる。`seenIntro` で一度だけ。
- 効果音は WebAudio 合成、`navigator.vibrate` で触覚。
- トースト: 「木材 +2」などをマップ上に浮かせて消す（Canvas に描く）。失敗理由は画面下部に短く出す。

## 描画

- 1 マス = 32 ワールドピクセル。スプライトは 16×16 のドット絵を 2 倍で 32×32 にする。
- スプライトはコードで定義（文字の格子＋パレット）し、起動時に OffscreenCanvas / canvas に焼く。
  **名前で引く**（`getSprite('tree')`）ので、後から画像素材に差し替えられる。
- `imageSmoothingEnabled = false`。devicePixelRatio を考慮。見えるマスだけ描く。
- 描く順: 地面 → 畑の土・作物 → 配置スペース（模様替え時）→ 家具・資源・看板・宝箱・プレイヤーを y でソート → ハイライト → トースト → スティック。
- 叩いたときに対象を少し揺らし、破片を数個飛ばす。壊れたら消える。
- カメラはプレイヤーを滑らかに追う（マップ外は映さないよう端で止める。マップが画面より小さい方向は中央寄せ）。

## 保存

- `localStorage['survival-island:save:v1']`。行動のたびと、5 秒ごとの位置、`visibilitychange` で保存。
- 読み込み時に欠けたフィールドは既定値で埋める（形式が増えても壊れない）。
- 1 セーブの大きさは実測して README に書く。
